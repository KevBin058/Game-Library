# Welcome to my game library.

This respiratory contains all of the games I have built for nearly a decade of using Scratch, as far back as 2018, including games that I have collaborated with.

All games I have uploaded to the Scratch website is under the CC-by-License, so anyone can remix them.

All other licensed or unlicensed games are not meant to be open-source as I am very passionate of the work I put in. That means I'm not really in the favor of others ripping and modding my other games, sorry.
